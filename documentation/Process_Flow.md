# Process Flow

```text
Request Submitted
        ↓
Credit Review
        ↓
Awaiting Customer Documents
        ↓
Account Created
        ↓
Welcome Package Sent
        ↓
Account Active / Ready for Order
```

## Supporting Milestones

- DocuSign packet sent to customer
- Customer reminder
- DocuSign received
- Application forwarded to Credit
- Account creation
- Welcome package sent

## Separate Outcome

`Opportunity Lost` is analyzed separately because it represents an outcome rather than a normal onboarding stage.
