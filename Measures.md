# DAX / Measure Documentation

The Power BI report uses DAX to support KPI calculations and elapsed-time analysis.

## Core KPI Concepts

- Total onboarding opportunities
- Active account count
- Pending request count
- Lost opportunity count
- Elapsed onboarding time
- Stage-level cycle time

## Modeling Approach

Milestone dates are used to calculate elapsed time between key onboarding activities. Status is used to distinguish work in progress, active accounts, and lost opportunities.

The exact DAX implementation is contained in the Power BI report.
