# KPI Definitions

| KPI | Definition |
|---|---|
| New Account Opportunities | Total onboarding records in the dataset |
| Active Accounts | Accounts with status `4 - Account Active` |
| Pending Requests | Active onboarding records that have not reached Account Active or Opportunity Lost |
| Lost Opportunities | Records with status `5 - Opportunity Lost` |
| Onboarding Status | Current stage/outcome of the onboarding record |
| Elapsed Time | Difference between defined onboarding milestone dates |
| Roadblock Category | High-level classification of an account setup issue |

## Reporting Note

Pending accounts are treated as work in progress and are not automatically classified as failed conversions.
